# Cosmos Quiz

Quiz de astronomia e astrofísica com curiosidades, feito em React.

🔗 **Acesse:** https://SEU-LINK.vercel.app

## Funcionalidades
- 10 perguntas com explicação após cada resposta
- Pontuação e nível final
- Progresso salvo no navegador
- Curiosidades sobre astrofísica

## Conceitos aplicados
- Variáveis: `pontos`, `indice`
- Condicionais: verificação da resposta
- Repetição: `.map()` nas alternativas e `for...of` nos níveis
- Hooks: `useState` (estado) e `useEffect` (localStorage)

## Como rodar
npm install
npm run dev
